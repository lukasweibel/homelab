# Overview

## What this is

This repository defines the GitOps and host configuration for a personal homelab cluster. Argo CD applies the Kubernetes state from the main branch.

## Key capabilities

1. Kubernetes applications and cluster configuration.
2. Host setup and deployment scripts.

## Out of scope

1. Imperative changes to the live cluster as a replacement for repository changes.

## Stack

Kubernetes, Argo CD, Helm, YAML, Docker Compose, shell scripts, and GitHub Actions.
